# Meyo AI Interaction Project

Proyecto universitario social-filosófico que explora la interacción
humana con inteligencia artificial mediante respuestas automáticas
generadas por un LLM local (LM Studio) en la app Meyo.

## Technologies
- Python
- Appium + UIAutomator2
- LM Studio
- Android

## Ethical Notice
Este proyecto se desarrolla con fines exclusivamente académicos.
